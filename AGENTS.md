# Beyond the Stack Notes — Repository Instructions

## Scope

This repository owns reader-facing runnable companions to Beyond the Stack articles: original notebooks, small experiments, their setup, evidence, and limitations. Article prose and publishing belong in the Blog repository. Coursework and private experiments belong in Beyond the Stack Labs.

Read the relevant companion README before editing. Keep examples independently understandable, preserve unrelated work, and do not copy private Labs material into this public repository without a publication review.

## Environment and verification

Use this repository's `.venv`; do not use or modify the Labs shared environment. Follow the root README for setup and launch JupyterLab from this repository root. Run checks proportionate to the change, state what actually ran, and treat saved notebook outputs as historical evidence rather than a fresh execution.

Keep credentials, private inputs, local paths, environments, caches, model weights, and bulky generated artifacts out of Git. Review notebooks and retained history for sensitive data before publication.

## Git and publication

This is a public repository. Inspect status, diffs, remote, and outgoing commits before pushing. Do not force-push, rewrite published history, change visibility, or publish unrelated work without explicit authorization. Blog or Labs Git permissions do not transfer here.
